# Gold Coast character assets

Source: Ultimate Modular Men by Quaternius
https://quaternius.com/packs/ultimatemodularcharacters.html

License: CC0 1.0 Universal. Original notice is in License.txt.

All eleven original individual glTF characters are included in Customize.
Suit.gltf is also the dealer. Files are self-contained, including their rigs
and animations. The browser loads only selected/visible characters and reuses
one download per model. Each person receives an independent skeleton and colors.
Idle and Walk are used; sitting is a procedural leg pose layered on Idle.
No Unity runtime or external asset service is required.
